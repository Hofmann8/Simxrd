# 晶体结构显示组件

本项目使用React和JSmol实现了一个交互式的晶体结构显示组件，可以显示不同类型的分子筛结构。

## 功能特点

- 支持多种分子筛结构的显示（FAU、LTA、SOD）
- 多种显示样式（球棍模型、空间填充、线框模型等）
- 支持旋转、缩放和重置视图
- 显示晶胞和原子标签
- 测量原子间距离和角度
- 显示静电势表面
- 导出为多种格式（PNG、JPG、XYZ、MOL）

## 使用方法

1. 确保已安装JSmol库
2. 将XYZ文件放在public/xyz_data目录下
3. 使用CrystalStructureDisplay组件显示晶体结构

## 项目概述

本项目是一个基于 React 和 JSmol 的分子筛晶体结构查看器，用于可视化和分析不同类型的分子筛结构。

## 主要功能

- 显示多种分子筛结构（FAU、LTA、SOD等）
- 支持多种显示样式（球棍模型、线框模型、空间填充等）
- 显示单元格和原子标签
- 旋转和重置视图
- 导出图像（PNG、JPG）和结构文件
- 显示结构信息和统计数据

## 技术栈

- React.js
- JSmol（用于3D分子结构可视化）
- React Icons
- CSS-in-JS样式解决方案

## 组件结构

晶体结构显示功能由以下组件组成：

1. `CrystalStructureDisplay` - 主组件，整合所有子组件
2. `ToolsPanel` - 提供工具和控制选项
3. `ViewerPanel` - 包含JSmol查看器
4. `InfoPanel` - 显示结构信息和统计数据

## 使用方法

在 ReferenceStructure 页面中，用户可以：

1. 从下拉菜单中选择要查看的分子筛结构
2. 使用工具面板更改显示样式
3. 显示/隐藏单元格和原子标签
4. 旋转结构或重置视图
5. 导出图像或结构文件
6. 查看结构信息和统计数据

## 性能优化

- 使用 useRef 和 useEffect 管理 JSmol 实例的生命周期
- 延迟更新计数，避免在同一渲染周期内多次更新状态
- 在切换模型或样式时暂时停止旋转，减少渲染负担
- 优化样式应用方式，避免不必要的重渲染

## 数据来源

结构信息从 data.json 文件中加载，包含各种分子筛的晶体学数据和应用信息。
