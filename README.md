## 功能特点

- XRD 数据模拟与分析
- 晶体结构三维可视化
- 支持多种晶体结构模型
- 支持 Web 和桌面应用模式
- **参考晶体结构库**：包含多种典型沸石结构的三维可视化模型
  - 支持 FAU、LTA、SOD 等典型沸石结构
  - 提供详细的结构信息和特征描述
  - 可调整显示风格和坐标轴显示
- **文件导入**：支持导入自定义 XYZ 格式的晶体结构文件
- **结构分析**：提供基本的结构参数和特征分析
- **跨平台支持**：Web 浏览器和桌面应用程序双重支持

## 常见问题解决

### 在 React 中使用 Node.js 模块

React 应用在浏览器环境中运行，不能直接使用 Node.js 模块（如 path、fs 等）。在 Electron 应用中，我们通过以下方式解决这个问题：

1. 使用 contextBridge 在预加载脚本中暴露安全的 API
2. 在渲染进程中通过 window.electronAPI 调用这些 API
3. 避免在 React 组件中直接导入 Node.js 模块

### 文件路径问题

在 Electron 中，文件路径需要特殊处理：

1. 使用 file:// 协议加载本地文件
2. 注册自定义协议处理器处理文件请求
3. 使用绝对路径而非相对路径

## 参考晶体结构页面

参考晶体结构页面提供了常见沸石结构的三维可视化和详细信息：

1. **左侧选择面板**：
   - 列出所有可用的参考结构
   - 支持结构搜索功能

2. **信息面板**：
   - 显示基本结构描述和主要特征
   - 可展开/折叠特征列表
   - 可切换显示/隐藏详细信息

3. **详细信息卡片**：
   - 基本晶体学参数（晶系、空间群、晶胞参数等）
   - 结构特征（骨架结构、孔径尺寸等）
   - 化学组成和主要应用

4. **JSmol 可视化**：
   - 三维交互式显示
   - 支持多种显示风格（线框、球棒模型）
   - 坐标轴显示选项，帮助理解空间方向

## 使用方法

1. 从左侧面板选择一个晶体结构
2. 使用顶部工具栏调整显示选项
3. 点击"显示详情"查看完整的结构信息
4. 使用鼠标在 JSmol 视图中旋转、缩放和平移结构模型
