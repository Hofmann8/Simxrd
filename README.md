# SimXRD-DUT

SimXRD-DUT 是一个用于模拟和分析X射线衍射(XRD)数据的应用程序，专为材料科学研究人员设计。

## 主要功能

- XRD模拟：根据输入参数生成模拟的XRD图谱
- 参考晶体结构：查看和分析常见晶体结构
- 数据导出：将模拟结果导出为CSV格式
- 交互式图表：动态显示XRD衍射图谱

## 技术栈

- React.js
- Electron (桌面应用)
- ECharts (图表可视化)
- JSmol (晶体结构可视化)
- Bootstrap (UI框架)

## XRD 模拟系统

### 真实 XRD 模拟（测试版）

该功能通过结合理论计算和实验数据，实现了 XRD 图谱的实时模拟。

#### 主要特点

1. 多数据源融合
   - 理论模拟：基于晶体结构参数的理论计算
   - 实验数据：来自真实实验的 XRD 测试结果
   - 插值结果：结合理论和实验的综合预测

2. 参数影响模拟
   - SiO₂/Al₂O₃ 比例：影响骨架结构，调整峰位置
   - Na₂O/SiO₂ 比例：影响结晶度，调整峰强度
   - H₂O/SiO₂ 比例：影响晶化速率
   - 时间：影响结晶完整度
   - 温度：影响峰形和峰宽

3. 实时动态显示
   - 支持动态生成过程展示
   - 可调节模拟速度
   - 提供暂停/继续控制

4. 匹配度分析
   - 综合置信度评估
   - 相关系数计算
   - 均方根误差分析
   - 峰位匹配度评估

#### 使用说明

1. 输入参数范围：
   - SiO₂/Al₂O₃：3-10
   - Na₂O/SiO₂：0.5-2
   - H₂O/SiO₂：10-25
   - 时间：2-24小时
   - 温度：70-100℃

2. 结果解读：
   - 蓝色实线：当前参数下的预测结果
   - 绿色虚线：最接近的实验数据
   - 红色虚线：理论计算结果

## 功能特点

- XRD 数据模拟与分析
- 晶体结构三维可视化
- 支持多种晶体结构模型
- 支持 Web 和桌面应用模式
- 参考晶体结构库：包含多种典型沸石结构的三维可视化模型
- 文件导入：支持导入自定义 XYZ 格式的晶体结构文件
- 结构分析：提供基本的结构参数和特征分析
- 跨平台支持：Web 浏览器和桌面应用程序双重支持

## 使用说明

1. 输入实验参数
2. 点击"开始模拟"
3. 查看模拟结果和匹配建议
4. 根据建议调整参数

## 技术实现

- 使用 React 构建用户界面
- JSmol 用于三维分子结构可视化
- Bootstrap 提供响应式布局
- Electron 用于桌面应用程序打包
