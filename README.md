# SimXRD - X射线衍射模拟工具

SimXRD是一个用于X射线衍射模拟的桌面应用程序，基于Electron和React构建。

## 主要功能

- XRD模拟：根据输入参数生成模拟的XRD图谱
- 参考晶体结构：查看和分析常见晶体结构
- 数据导出：将模拟结果导出为CSV格式
- 交互式图表：动态显示XRD衍射图谱

## 技术栈

- React.js
- Electron (桌面应用)
- ECharts (图表可视化)
- JSmol (晶体结构可视化)
- Bootstrap (UI框架)

## XRD 模拟系统

### 真实 XRD 模拟（测试版）

该功能通过结合理论计算和实验数据，实现了 XRD 图谱的实时模拟。

#### 主要特点

1. 多数据源融合
   - 理论模拟：基于晶体结构参数的理论计算
   - 实验数据：来自真实实验的 XRD 测试结果
   - 插值结果：结合理论和实验的综合预测

2. 参数影响模拟
   - SiO₂/Al₂O₃ 比例：影响骨架结构，调整峰位置
   - Na₂O/SiO₂ 比例：影响结晶度，调整峰强度
   - H₂O/SiO₂ 比例：影响晶化速率
   - 时间：影响结晶完整度
   - 温度：影响峰形和峰宽

3. 实时动态显示
   - 支持动态生成过程展示
   - 可调节模拟速度
   - 提供暂停/继续控制

4. 匹配度分析
   - 综合置信度评估
   - 相关系数计算
   - 均方根误差分析
   - 峰位匹配度评估

#### 使用说明

1. 输入参数范围：
   - SiO₂/Al₂O₃：3-10
   - Na₂O/SiO₂：0.5-2
   - H₂O/SiO₂：10-25
   - 时间：2-24小时
   - 温度：70-100℃

2. 结果解读：
   - 蓝色实线：当前参数下的预测结果
   - 绿色虚线：最接近的实验数据
   - 红色虚线：理论计算结果

# SimXRD-DUT 应用

SimXRD-DUT 是一个用于模拟和分析 XRD 衍射图谱的应用程序，专为材料科学研究设计。

- 添加了对 48h、72h 和 96h 特殊晶化时间的支持

- 通过确认对话框提示用户参数变更，确保实验数据的准确性

## 文件路径处理

在Electron应用程序中，文件路径处理是一个常见的问题，特别是在开发环境和生产环境之间切换时。本项目采用了以下策略来解决这个问题：

### 开发环境

在开发环境中，静态资源文件位于`public`目录下，可以通过相对路径直接访问：

```
/xyz_data/FAU.xyz -> public/xyz_data/FAU.xyz
```

### 生产环境

在生产环境中，静态资源文件被打包到`build`目录下，然后复制到应用程序的资源目录中。为了正确访问这些文件，我们实现了以下机制：

1. **文件协议处理器**：注册自定义的`file://`协议处理器，用于处理文件URL。

2. **路径转换**：提供`convertFilePath`方法，将相对路径转换为绝对路径。

3. **文件存在检查**：提供`fileExists`方法，检查文件是否存在。

4. **资源路径获取**：提供`getResourcePath`方法，获取应用程序资源目录中的文件路径。

5. **文件内容读取**：提供`readFile`方法，直接读取文件内容。

### 解决方案

为了解决在electron-prod环境中文件读取失败的问题，我们采取了以下措施：

1. **多路径尝试**：在查找文件时，尝试多个可能的路径：
   - 应用程序资源目录：`process.resourcesPath/app/build/...`
   - 应用程序目录：`__dirname/../build/...`
   - 当前目录：`./...`

2. **extraResources配置**：在`electron-builder`配置中，添加`extraResources`配置，确保静态资源文件被正确复制到应用程序的资源目录中。

3. **日志输出**：添加详细的日志输出，以便在生产环境中调试文件路径问题。

4. **错误处理**：添加更多的错误处理，确保在文件读取失败时能够提供有用的错误信息。

5. **空值处理**：添加对null和undefined值的检查，避免空值引用错误：
   - 在所有文件路径处理函数中添加空值检查
   - 在组件中添加条件渲染，避免传递空值给子组件
   - 提供友好的错误提示，帮助用户理解问题

## JSmol集成

本项目使用JSmol库来实现晶体结构的3D可视化。JSmol是一个基于JavaScript的分子可视化工具，可以在浏览器中显示3D分子结构。

### 集成方式

1. **JSmol库加载**：在`public/index.html`中加载JSmol库，并设置全局配置。

2. **路径处理**：使用相对路径`./jsmol/j2s`加载JSmol库，确保在开发环境和生产环境中都能正确加载。

3. **初始化策略**：
   - 使用异步加载方式，等待JSmol库加载完成
   - 添加超时处理，避免无限等待
   - 提供友好的错误提示，帮助用户理解问题

4. **错误处理**：
   - 添加对JSmol库加载失败的处理
   - 添加对JSmol初始化失败的处理
   - 添加对JSmol脚本执行错误的处理

5. **性能优化**：
   - 设置Canvas的`willReadFrequently`属性为true，提高Canvas2D性能
   - 优化JSmol初始化参数，减少内存占用和提高渲染速度
   - 使用适当的渲染设置，平衡质量和性能
   - 禁用不必要的功能，如调试模式、控制台等
